🔍 API Inspector

Capture, inspect, modify, and resend API requests with full cookie support.

Inspector Window (standalone): 1. Click "Open Inspector Window"
2. Pick a tab from the "Listening to" dropdown
3. Trigger API calls on that tab — they appear here
4. Edit and "Send Request" runs against that tab
DevTools Panel: Open Chrome DevTools (F12) → "API Inspector" tab. Bound to the current tab only.
